# Lookmaxing (nom provisoire)

Quiz mobile, scan du visage (2 photos, jamais enregistrées) et plan de 28 jours. Marché français.

- Essayer en local, sans aucune clé : `node dev/server.mjs`, puis ouvrir http://localhost:8788/q/
- Tests : `node test/flow.test.mjs` et `node test/units.test.mjs`
- Composants : http://localhost:8788/design/
- Le travail de reconstruction (recon, architecture, design, journal) : `replica/`

Node 22 ou plus, aucune dépendance.
